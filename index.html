Main projects

Some of the bigger things I’ve worked on at dbt Labs.

  • Writing to Iceberg catalogs from dbt

    I built a demo that writes from a local dbt project to Snowflake and Databricks with one config change. I also contributed the DuckDB write options that helped make it possible.

  • Developer experience for dbt Fusion

    I wrote migration guidance for package maintainers, asked the community for feedback on logging, and created issue forms for people trying the new engine.

  • dbt Charts

    I contribute to the open source tool for building dashboards with SQL and YAML. I’ve used it for Crawl Atlas and Dashboard Bakeoff.

Writing and talks

  • Iceberg?? Give it a REST!

  • The Iceberg ecosystem today

Open source contributions

DuckDB and Iceberg

  • Iceberg catalog write compatibility

    Added options for writing from DuckDB to Iceberg REST catalogs with different write capabilities.

  • Creating Iceberg schemas concurrently

    Fixed CREATE SCHEMA IF NOT EXISTS when a concurrent operation creates the same Iceberg schema first.

  • Consistent Iceberg catalog lookups

    Fixed a DuckDB cache issue so table names that differ only by case resolve consistently.

  • Uppercase identifiers in DuckDB

    Added an uppercase mode for unquoted SQL identifiers to help tools interoperate with engines like Snowflake.
