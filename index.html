Anders Swanson

I build open source data tools with the people who use them. I became one with the database from the outside in. I started with what different warehouses could do, got into SQL syntax and parsing, and then got deep into logical plans. Famously, I don’t care about execution optimization.

Main projects

  • Incubating dbt features

    At dbt Labs, I incubated some of dbt’s hallmark features with the community. That includes dbt v2, the dbt Information Schema and Checks, Iceberg catalog support, Python models, materialized views, and Cross-platform dbt Mesh.

  • dbt adapters

    • Helped create dbt-synapse and dbt-firebolt.
    • Shepherded the Databricks, Starburst (Trino), and Microsoft Fabric adapters onto the dbt platform. I also worked on MotherDuck support in dbt.
    • Rewrote the DuckDB and ClickHouse adapters for dbt v2.
  • Cross-platform dbt Mesh and Iceberg

    I built an early Iceberg prototype for cross-platform dbt Mesh, which dbt Labs announced at Coalesce 2024. Later, I contributed DuckDB write options and showed one local dbt project writing to Snowflake and Databricks with a single config change.

  • dbt Charts

    I contribute to the open source tool for building dashboards with SQL and YAML. I’ve used it for Crawl Atlas and Dashboard Bakeoff.

Writing and talks

  • A Catalog Is All You Need

    A Roundup essay and demo on using a local dbt project with DuckDB to write to Snowflake and Databricks catalogs.

  • Iceberg?? Give it a REST!

    A Roundup essay on what Iceberg REST catalogs make possible when multiple engines share the same tables.

  • The Iceberg ecosystem today

    A Roundup podcast conversation with Tristan Handy about what works in production and where Iceberg catalogs still get tricky.

  • Fusion Diaries

    Community updates on Fusion’s progress, rough edges, and next steps. Also see the Coalesce edition.

  • Open source tea leaves: Reading Iceberg’s proposed future

    A dbt Summit peer exchange on proposals and trade-offs in Apache Iceberg.

  • RFC: Columnar validation with Arrow, ADBC, and DuckDB

    A proposal for a shared way to validate data across files and warehouses in Great Expectations.

  • Proposal: Uppercase SQL identifiers in DuckDB

    Proposed a setting for Snowflake and Oracle style identifier casing, which I later implemented in DuckDB.

  • Proposal: External tables in dbt Core

    A discussion about letting dbt create and manage external tables declared in a project.

Open source contributions

DuckDB and Iceberg

  • Iceberg catalog write compatibility

    Added options for writing from DuckDB to Iceberg REST catalogs with different write capabilities.

  • Creating Iceberg schemas concurrently

    Fixed CREATE SCHEMA IF NOT EXISTS when a concurrent operation creates the same Iceberg schema first.

  • Consistent Iceberg catalog lookups

    Fixed a DuckDB cache issue so table names that differ only by case resolve consistently.

  • Uppercase identifiers in DuckDB

    Added an uppercase mode for unquoted SQL identifiers to help tools interoperate with engines like Snowflake.
